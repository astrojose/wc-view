# wc-view v0.8.1

## Fixes

- **Clean port-conflict errors**: `wc-view serve` now surfaces a clear, actionable error when the requested port is already in use, instead of crashing with an unhandled `EADDRINUSE` stack trace.
- **No more silent "queued forever"**: `wc-view serve` warns on startup when a workspace already has feedback batches queued but no `--agent-command` bridge attached, so pending feedback doesn't go unnoticed.
- **Visible bridge status in the browser**: the Review Activity drawer's status chip now reflects whether an agent bridge is actually attached — flipping from "Live Feed" to "No Agent Attached" — instead of always claiming a live feed regardless of whether anything is processing feedback.
