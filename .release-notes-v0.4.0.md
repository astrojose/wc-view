# wc-view v0.4.0

## Highlights

- Browser feedback now creates one durable, idempotent batch that starts connected agent work without a second chat prompt.
- `wc-view bridge --command <command>` claims feedback batches, invokes an adapter, and persists progress and results.
- The browser receives replayable batch status through Server-Sent Events.
- Scratch artifacts may be updated automatically. Protected project artifacts require explicit acceptance before the bridge can apply them.
- Client assets are served without cache storage so a restarted local review surface uses the current workflow.

## Install / test

```bash
npx @astrojose/wc-view@0.4.0 --help
```
