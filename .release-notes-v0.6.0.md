# wc-view v0.6.0

## Highlights

- **Standalone Offline Export**: Export Markdown review documents and Mermaid diagrams to zero-dependency standalone HTML via `wc-view export <file> [--out <path>]`.
- **Two-Way Agent Dialogue Feed**: Post agent replies directly to review batches with `wc-view feedback reply <batchId> --message <text>` and view live conversation threads in the sliding browser Activity Drawer (`💬 Feed`).
- **Interactive Decision Checklists**: Clickable GFM task lists (`- [ ]` / `- [x]`) that automatically stage structured decision notes into the composer.
- **Recursive Multi-Document Sidebar**: Recursively browse documentation trees with instant search filtering and in-browser file switching.
- **Live Document Hot-Reloading**: Real-time SSE synchronization when documents are edited on disk without losing in-progress reviewer notes.
- **Visual Polish**: Code diff syntax highlighting (`+`/`-`/`@@`), dynamic Mermaid re-theming on Dark/Light switch, and an accessible Keyboard Shortcuts modal (`?`).
- **Programmatic Feedback Resolution**: Resolve feedback items, batches, and notes via `wc-view feedback resolve <id>` and format checklist outputs with `wc-view feedback --format markdown`.
