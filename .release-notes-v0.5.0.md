Package: `@astrojose/wc-view`

## Highlights

- Adds first-class `.html` and `.htm` artifact rendering in the local review surface.
- Makes `.wc-view-scratch.html` the styled scratch-artifact path so accepted browser feedback can update expressive HTML output by default.
- Applies the wc-view design system to document typography, tables, code blocks, blockquotes, annotation affordances, sticky status, and the floating composer.
- Fixes packaged client chunk serving and reads the CLI version from package metadata.

## Install and Test

```bash
npx @astrojose/wc-view@0.5.0 --help
```

Contributor testing can also use the GitHub Release assets and npm pack artifact before installing from npm.

## Verification

- `./node_modules/.bin/tsc --noEmit`
- `npm test`
